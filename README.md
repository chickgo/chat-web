My Chat Application

Hello!I'm ChickGo,a developer passionate about technology and exploring new things.I've created this simple chat application designed to provide an easy and friendly online communication platform.


Project Introduction

This chat application is built with Node.js,Express,and Vue.js,connected to MongoDB Atlas for backend storage.It offers basic functionalities such as user registration,login,sending messages,and viewing message lists.


Features


• User Registration:New users can register an account and create a profile.

• User Login:Registered users can log in to the application.

• Send Messages:Logged-in users can send text messages to other users.

• View Messages:Users can view all public messages.


Technology Stack


• Backend:Node.js,Express

• Database:MongoDB Atlas

• Frontend:Vue.js

• Styling:CSS


How to Run


1. Clone the repository:

```bash
   git clone https://github.com/chickgo/chat.git
   ```


2. Install dependencies:

```bash
   cd chat
   npm install
   ```


3. Run the application:

```bash
   npm start
   ```


4. Access the application:Open your browser and visit`http://localhost:3000`.
